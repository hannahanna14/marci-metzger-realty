# Images — Replace These With Real Photos

Place image files in this folder (`public/images/`). Vite serves these files
from `/images/` during development and includes them in production builds.

## Required Files

### Logo
- `Logo.png` — Navbar logo

### Hero
- `hero-bg.jpg`  — Full-width desert/mountain landscape (hero background)

### About
- `marci-portrait.jpg`  — Marci's headshot / portrait photo

### Gallery (11 images)
- `gallery/gallery-1.jpg` through `gallery/gallery-11.jpg`

### Contact
- `contact-bg.jpg` — Contact section background

## Tips
- Download directly from marcimetzger.com (right-click → Save image as…)
- Recommended sizes: hero ~1920×1080px, portrait ~600×800px, gallery ~800×600px
- Keep file names exactly as listed above
